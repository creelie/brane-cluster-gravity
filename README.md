# Ultraviolet Bounds and the Positivity Obstruction in Brane-Cluster Gravity

The manuscript and standalone LaTeX sources are in the **papers** folder.
Extract the source ZIP and select **manuscript.tex** as the main document.
Compile with pdfLaTeX. Run it again to resolve the references.
The bibliography and all figure inputs are included.

The paper revises the [posted Preprints.org v2](https://www.preprints.org/manuscript/202508.0407/v2).
It derives a stochastic brane form factor, isolates the Euclidean ultraviolet
power-counting and one-loop statements, and proves a positivity obstruction
in a linearized curvature channel.
